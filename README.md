# Ticketing_SystemSMS

A clean internal web ticketing system built for managing support tickets related to telecom/SMS issues.

## Features
- Create, edit, and delete tickets
- Fields: Customer/Client, Trunk, Destination/Country, Content, Issue, Vendor
- Statuses: Open, Close, Down Vendor
- Search and filter by status
- Responsive modern UI
